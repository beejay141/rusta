## Prerequisites

- Rust 1.79 or later (2021 edition)
- Cargo package manager

## What is Rusta?

Rusta is a modern Rust API framework that provides:

- **Clean Architecture** — Controller → Service → Repository layers
- **Declarative Routing** — `#[controller]`, `#[get]`, `#[post]` macros
- **Dependency Injection** — Container with `#[injectable]` and `#[inject]`
- **Built-in Observability** — APM tracing and structured logging
